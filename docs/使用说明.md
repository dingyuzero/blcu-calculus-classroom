左侧选章节，顶部选该章三个实验之一。右侧滑块和选项会实时更新画布、公式、结果和数值表；自由函数绘图需要点击“绘制函数”才应用表达式和范围。

| 操作 | 作用 |

| 课堂演示 | 隐藏侧栏与补充讲解，放大画布和结果；Esc 退出 |
| 重置实验 | 只恢复当前子实验的默认参数，不清除其他实验 |

用 Tab 切换控件、方向键操作滑块。每个实验的参数独立保存在本机浏览器，不跨电脑同步。隐私浏览、清理缓存、移动离线 HTML 的位置，可能改变保存行为；不影响本次课堂计算。切换章节停止动画，切换浏览器页签会暂停动画。

### 1. 函数与图像

表达式可以直接输入 `sin(x)`、`x^2`、`exp(x)`、`sqrt(x)`、`abs(x)`、`1/x`。**常用对数写 `log10(x)`；以 2 为底写 `log2(x)`；自然对数写 `ln(x)`。** `log(x)` 也保持自然对数含义。输入后点击绘制；对数建议横轴设为 0.1 到 10。

支持实数单变量 x、常数 pi/e 和基本四则、乘方运算。角度用弧度；乘法建议写 `2*x`，乘方写 `x^2`。不接受赋值、脚本、矩阵或隐函数。定义域外的点显示为未定义；遇到极点可手动设置纵轴或缩小区间。

平移与伸缩演示 `g(x)=A f(B(x−h))+k`，这里 B>0。依次只改变一个参数，比较方向与倍数；纵轴固定，越界数值可在表中查看。

反函数把 (a,f(a)) 与 (f(a),a) 同时画出。平方函数限制在 x≥0；指数与对数互换定义域和值域。先预测点的位置，再移动滑块验证。

### 2. 极限与连续

原有实验比较 sin(x)/x、左右跳跃和连续函数。ε–δ 实验固定 `f(x)=x²`，调整 ε 与 δ；“找到一个合适的 δ”使用解析不等式给出保证，不是仅从采样点猜测。中心点与邻域边界都不属于条件 `0<|x−a|<δ`。

数列实验比较 `1/n`、`(−1)^n/n`、`(−1)^n` 和 `(1+1/n)^n`。紫色离散点代表各项，误差带围绕已知极限。振荡不一定意味着发散；有限项的图形不能独立证明极限。

### 3. 导数与变化率

割线实验可以选择左右方向，比较 |x| 在 0 的不同单侧差商。导函数实验同时画出 f、f′ 与切线；函数零点和导数零点不同，驻点不必是极值点。

牛顿法先用 `x²−2=0`、x₀=1，逐步逼近 √2。再试 x₀=0 的水平切线；选择 `x³−2x+2=0`、x₀=0 会出现 0→1→0 循环。残差 |f(xₙ)| 不是未经条件保证的根位置误差。固定画布可能容不下跑远的点，完整过程见表格。

### 4. 积分与累积

黎曼和比较左、中、右矩形，并区分有向积分与几何面积。试 `f(x)=x`、区间 [−2,2]：积分为 0，几何面积为 4。

变上限积分展示 `F(x)=∫ₐˣ f(t)dt` 和 `F′(x)=f(x)`。上限小于下限时方向反转；阴影只表示积分区间，不直接等于正的累积量。

数值积分同时比较中点法、梯形法、Simpson 法与解析积分。n 始终为偶数，方便每两个小区间拟合一段抛物线。先选 x² 验证 Simpson 的多项式精确性，再选 eˣ 比较误差随分割数的变化。

### 5. 泰勒展开

原有实验可改变展开中心、阶数和检验点，并展开本阶多项式。误差实验画出 `f−Tₙ`，显示检验点的 Lagrange 余项上界。虚线只对应当前检验点，不是图上所有位置的统一误差保证；上界可以很保守。接近机器精度时加阶不保证显示误差继续变小。

几何级数部分和从 k=0 到 n，共 n+1 项。比较 q=0.5、−0.8、1、−1、1.2。只有 |q|<1 时无穷和等于 1/(1−q)；在范围外这个分式有值也不能当作级数的和。

### 6. 数学与心理学

原有实验含学习曲线和正态密度／区间概率。遗忘模型展示指数衰减与理想化复习重置；基线半衰期为 ln(2)/k，复习瞬间恢复到 1，衰减率不改变。空心／实心点区分跳变前后。

心理测量曲线使用 Logistic 模型，x₀ 是 50% 阈值，最大斜率为 k/4。本例没有猜测率、失误率或真实数据拟合。所有心理学模型仅用于教学，不进行个人评估或诊断。

## 课堂路线建议

1. **函数与导数，约 25 分钟**：自由绘图预测学习曲线 → 割线与切线 → 导函数 → 回到学习曲线解释进步速率。
2. **微积分基本定理，约 20 分钟**：黎曼和 → 变上限积分 → 对照 F′=f → 用三种数值积分比较误差。
3. **近似与收敛，约 20 分钟**：泰勒逐阶逼近 → 余项估计 → 几何级数比较半径内外及端点。

## 常见问题

- **输入后图没变**：自由绘图需要点击“绘制函数”；其他实验即时更新。错误参数会保留上一次有效结果，先处理红色提示。
- **复制网址后参数没带过去**：网址保存当前实验入口，不包含个人参数。需要说明设置时，导出 SVG 或 CSV。
- **图形或字体缺失**：单文件版重新下载完整 HTML；多文件版完整解压。外部资料需要联网，实验本身不依赖 CDN。
- **文件直接打开受浏览器策略限制**：可改用公开网址；多文件版也可用 `python -m http.server 8765 --bind 127.0.0.1` 启动本地服务。该备用方法才需要 Python。
- **手机能否使用**：布局支持窄屏，控件会移到图下。正式授课建议电脑或平板横屏；真机触控与实际教室投影仍需现场确认。
